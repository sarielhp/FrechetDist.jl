Computational Geometry Primitives

FrechetDist builds on BasicCompGeometry for its geometric types and operations: Point (an SVector), Segment, Line, PntSeq (a polygonal curve), BBox, dist, convex_comb, and so on. See that package's documentation for them.

Floating-point primitives

The Frechet algorithms depend on a few primitives with specific floating-point behavior: convex_comb snaps to an endpoint when the parameter is within 1e-6 of it, nearest-point and segment-distance computations treat degenerate cases explicitly, and distances use @fastmath accumulation. These are kept here, with an fp_ prefix, so that results do not change with the BasicCompGeometry formulations.

FrechetDist.fp_convex_coef — Method
fp_convex_coef( seg, p )

Coefficient d(seg.p, p) / |seg|, or 0 for a degenerate segment.

source
FrechetDist.fp_convex_comb — Method
fp_convex_comb( p, q, t )

(1-t) p + t q, returning p and q exactly at t == 0 and t == 1. There is no snapping band: a fixed band in t moves points by a distance proportional to the edge length, which distorts long edges.

source
FrechetDist.fp_dist_point_segment — Method
fp_dist_point_segment( qr, s_p, s_q )

Distance from qr to the segment s_p-s_q, computed from the quadratic a t^2 + b t + c without constructing the nearest point. Values below 1e-20 max(a, c) (squared, relative to the scale of the inputs) are reported as zero.

source
FrechetDist.fp_dist_segment_segment — Method
fp_dist_segment_segment( a_p, a_q, b_p, b_q )

Minimum distance between the segments a_p-a_q and b_p-b_q. Solves the 2x2 normal equations, snaps the solution to the segments, and takes the minimum with the four endpoint-to-segment distances. Parallel (rank one) systems fall back to the endpoint distances.

source

Curve helpers

FrechetDist.Polygon_simplify_ext — Method
Polygon_simplify_ext

Simplify the input curve P, where every vertex in distance larger than r is added to the simplification. Maybe the cheapest and simplest simplification algorithm. Works for all measures. Returns the simplification and the indices of the vertices kept (both empty for an empty curve).

source
FrechetDist.read_file — Function
read_file

Reads a curve from a text file with one point per line (see BasicCompGeometry.ReadWrite.read_plt). A curve with at most one point is completed to a two point curve by repeating that point.

source
FrechetDist.remove_consecutive_duplicates — Method
