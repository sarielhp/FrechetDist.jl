FrechetDist.extract_refined_polygon — Function
extract_refined_polygon( P, pes, num_points_to_add, delta )

Refine edges along which pes (the sequence of matching points
along P is not monotone, so that the returned polygon has
vertices, which hopefully force the Frechet morphing computed in
the next iteration to be monotone.

Arguments

P : the polygo pes: Sequence of events long the polygon P num_points_to_add: how many points to add between points of non-monotonicity. The default is 1. Having a larger value speeds up the process of getting rid of non-monotonicity, but the polygons grow faster.

FrechetDist.frechet_mono_via_refinement — Function
frechet_mono_via_refinement( P, Q, approx )

Computes the monotone Frechet distance between P and Q using the
ve_r algorithm, refining the curves (adding vertices) until the
monotonized morphing's leash is within a factor `approx` of the
VE-retractable distance, a lower bound stored in `m.lower_bound`.
In the worst case it only approximates the Frechet distance.

Observe, that this function might be too slow if the two curves
are huge, since it does not simplify them before computing the
distance.

Returns

Returns a 4-tuple ( m, f, P, Q ): m: Morphing realizing result. f: true if the monotone leash equals the VE-retractable distance, so that the leash is the Frechet distance. P: Refined first input polygon Q: Refined second input polygon

FrechetDist.add_points_along_seg! — Function
add_points_along_seg!( pout, times, seg, n_mid_points = 1 )

Arguments

seg: t[1], t[2], .... , t[end]

 t[...]: Time stamps for points on the segment (all between 0 and 1)

Details

Add points along seg at time stamps specified by t, and add points in the middle between them (i.e., refining segment). These new points are added the output polygon pout. times is sorted and deduplicated in place.

Note, that one can set nmidpoints to be larger than 1, but it does not seem to be necessary/benefitial from the experimentation we did.

Output: Sorted( t[1]/2, t[1], (t[1]+t[2])/2, t[2],...)

FrechetDist.SweepDist_segs_p — Function
SweepDist_segs_p( p_a, p_b, q_a, q_b )

The oriented sweep distance (continuous dynamic time warping) between the oriented segments p_a p_b and q_a q_b: the integral, over the arc length of p_a p_b, of the distance between the point on p_a p_b and the corresponding point (at the same fraction of the way) on q_a q_b.
